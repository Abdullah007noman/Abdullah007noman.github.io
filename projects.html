Projects

  • Open Radio Access Network (O-RAN) Systems at TWiST Lab
    Contributing to the design and implementation of an Open Radio Access Network (O-RAN) system using OpenAirInterface (OAI) 5G NR, focusing on network flexibility, modularity, and interoperability. Exploring Near-Real-Time RAN Intelligent Controller (Near-RT RIC) functionalities and xApp-based control mechanisms for intelligent radio resource management and adaptive network optimization.
  • Spherical Interpolation for Real-Time Emitter Navigation
    Designed and configured a synchronized four-node Universal Software Radio Peripheral (USRP) system using OctoClock for coherent IQ signal acquisition and multi-receiver localization. Developed a MATLAB-based Spherical Interpolation (SI) algorithm for emitter position estimation using time-difference-of-arrival (TDOA) measurements from synchronized SDR receivers. Validated localization accuracy and robustness through indoor static and mobile experiments under varying emitter positions and mobility conditions.
  • Space–Ground Integrated Communication Systems
    Developed a reliable and secure multicast transport protocol for space–ground integrated networks using role-based access control (RBAC). Incorporated automated role verification, anomaly detection, and fault-tolerant communication mechanisms to address reliability and security challenges in heterogeneous satellite–terrestrial networks.
  • Machine Learning for Real-Time Image Enhancement
    Developed machine learning algorithms for image enhancement and green-screen removal, improving computational efficiency and processing accuracy for real-time image processing applications.
  • IoT-Based Intrusion Detection System (IDS)
    Developed a smart-home intrusion detection system using Raspberry Pi and IoT-enabled sensors for real-time monitoring and identification of unauthorized activities. Integrated sensor data with a centralized control unit to enable automated alerts and notifications.
  • Image Processing for Crack Localization
    Developed an image processing pipeline using edge detection and texture analysis techniques to identify and localize structural cracks in inspection images.
